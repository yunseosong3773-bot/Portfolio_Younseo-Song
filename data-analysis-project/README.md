Information Security Disclosure Data Analysis

This project analyzes corporate security investment trends and the effectiveness of the disclosure regulation using Information Security Disclosure data from 2016 to 2026.
---
Key Features

- 제도 효과 분석 (Policy Impact Analysis): 
  - 2022년 공시 의무화 제도 도입 전후의 공시 참여 기업 수 추이 분석  
  - Analyzed trends in corporate participation before and after the introduction of mandatory disclosure in 2022.
- 투자 비율 추이 (Investment Ratio Trends): 
  - 연도별 기업의 평균 및 중앙값 정보보호 투자 비율 시각화  
  - Visualized yearly trends in average and median corporate information security investment ratios.
- 데이터 전처리 (Data Preprocessing): 
  - 정제 및 필터링을 통한 분석 데이터 신뢰성 확보  
  - Cleaned and filtered data to ensure analytical reliability.

---
Tech Stack

- Language: Python
- Environment: Jupyter Notebook
- Libraries: Pandas, NumPy, Matplotlib, Seaborn
